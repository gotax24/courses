# 📚 Monorepo: Mi Ruta de Aprendizaje Fullstack 🚀

¡Bienvenido a mi archivo personal de estudio! 

Este repositorio es un **monorepo** que centraliza todos los cursos, prácticas, ejercicios y proyectos de aprendizaje que he desarrollado a lo largo de mi carrera como Ingeniero en Computación y Desarrollador Fullstack. 

Aquí documento mi evolución técnica: desde los fundamentos de la programación, pasando por la interactividad del Frontend con JavaScript/React, hasta la construcción de lógica de servidor y bases de datos en el Backend.

---

## 🗂️ Estructura del Repositorio

He clasificado los directorios según el área tecnológica y el propósito de estudio para facilitar su navegación:

### ⚙️ 1. Fundamentos y Herramientas
La base de todo desarrollo sólido y control de versiones.
* 📁 `Programacion-desde-0`: Lógica pura y algoritmos base.
* 📁 `git-desde-0`: Dominio de control de versiones, ramas y repositorios.
* 📁 `Ejercicios-de-programacion`: Retos de lógica y resolución de problemas.
* 📁 `retomando`: Ejercicios de calentamiento y repaso de conceptos.

### 🎨 2. Frontend Estático y Maquetación
* 📁 `html-desde-0`: Estructura semántica y accesibilidad web.
* 📁 `Css-desde-0`: Estilos, Flexbox, Grid y diseño responsivo.

### 🧠 3. Ecosistema JavaScript & TypeScript
* 📁 `Javascript-desde-0`: Core del lenguaje, ES6+ y asincronismo.
* 📁 `POO-JS`: Programación Orientada a Objetos aplicada en JS.
* 📁 `manejo-dom-js`: Manipulación directa del Document Object Model.
* 📁 `clousure`: Estudio profundo de los closures y el scope léxico.
* 📁 `typescript-desde-cero`: Tipado estático e interfaces para aplicaciones escalables.

### ⚛️ 4. Prácticas y Componentes UI (JS / React)
Proyectos aplicados para dominar estados, eventos y renderizado.
* 📁 `Twitter Follow Card`: Clon del componente de seguimiento de Twitter.
* 📁 `MouseFirebase`: Práctica de rastreo de eventos / integración.
* 📁 `Calculadora chimba`: Lógica matemática aplicada a interfaces.
* 📁 `Mi-primera-app`: Proyecto introductorio de estructuración de apps.
* 📁 `ejecicio-contador`: Manejo de estado básico.
* 📁 `ejercicio -suma`: Operaciones dinámicas en el DOM.
* 📁 `validacion-ejercicio`: Lógica de validación de formularios.

### 🗄️ 5. Backend y Bases de Datos (Arquitectura de Servidor)
* 📁 `php-desde-cero`: Lógica de servidor, sesiones y patrón MVC.
* 📁 `sql-desde-cero`: Modelado de datos, consultas relacionales y normalización.

## 💡 ¿Por qué un Monorepo?
Decidí agrupar todo en un solo lugar para:
1. Tener una **biblioteca de código de referencia rápida** (mis propios *snippets* y configuraciones).
2. Mantener mi GitHub limpio y profesional, separando mis ejercicios de aprendizaje de mis proyectos de producción (como sistemas de inventario o aplicaciones reales).
3. Mostrar transparencia sobre mi proceso de aprendizaje continuo (*Lifelong learning*).
